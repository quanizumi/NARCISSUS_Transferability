# NARCISSUS_Transferability

该实验是基于论文NARCISSUS : A Practical Clean-Label Backdoor Attack with Limited Information，选择了 "NARCISSUS触发器跨架构可转移性研究" 作为延伸方向

本仓库是华南师范大学计算机学院智能系统与防护课程设计作业，版权所有者为23级廖镇泉 章鸿辉 曾翔

# 摘要

后门攻击是深度学习模型面临的重要安全威胁之一。NARCISSUS作为一种实用的清洁标签后门攻击方法，仅利用目标类数据即可实现高效攻击。然而，关于其触发器在不同神经网络架构间转移能力的研究仍然有限。本文针对NARCISSUS触发器的跨架构可转移性进行了系统性的深入研究。通过对原始论文实验数据的深度分析，我们发现了几个重要的规律：触发器的转移性呈现出高度对称性，即从模型A转移到模型B与从模型B转移到模型A的成功率几乎相同；使用GoogLeNet作为替代模型可以产生具有最强转移性的触发器；此外，替代模型的容量与触发器的转移性呈现正相关关系。本研究为理解清洁标签后门攻击的转移机制提供了重要的实证依据，并对后门防御策略的设计具有重要的参考价值。

关键词：后门攻击，清洁标签，转移性攻击，深度神经网络，安全

# 特征

- 高度对称性：触发器的转移性是双向对称的，A→B的成功率与B→A几乎完全相同（差异仅0.05%）
- 最佳替代模型：GoogLeNet作为替代模型效果最佳，平均转移成功率达99.83%
- 跨架构优势：跨架构转移（96.84%）甚至略高于同架构转移（97.36%）
- 实用性强：这些发现意味着攻击者无需知道受害者使用什么模型架构就能实施有效攻击

# 使用说明

1.模型

代码中明确涉及两类模型：

- 代理模型：用于生成NARCISSUS触发器的模型。实验中测试了三种不同的神经网络架构：
  - ResNet-18
  - VGG-16
  - MobileNetV2
- 目标模型：用于评估触发器攻击成功率的模型。实验中同样使用了上述三种架构分别进行训练和评估。

2.数据集

实验使用CIFAR-10数据集。该数据集包含10个类别的60000张32x32彩色图片。代码中通过

torchvision.datasets.CIFAR10进行加载和预处理（包括随机裁剪、水平翻转、归一化等数据增强）。

3.关键参数说明

- TARGET_CLASS = 2：指定目标类别。代码中使用CIFAR-10的索引2，对应“鸟”类，即后门攻击的目标分类。
- POISON_RATIO = 0.005：投毒比例。设置为0.5%，即在训练目标模型时，从目标类样本中随机选择此比例的样本注入后门触发器。
- TRIGGER_EPSILON = 16 / 255：触发器生成的L∞范数约束。限制添加到图片上的触发器扰动幅度不超过16/255，以确保其对人眼不可见或难以察觉。
- TRIGGER_ITERATIONS = 500：触发器生成的优化迭代次数。用于在优化损失函数以生成有效触发器时的迭代步数。
- magnification=3.0：在评估触发器有效性时使用的触发器放大倍数。评估时会将生成的触发器按此倍数放大后应用于测试图片，以观察其攻击成功率。
